# Fix UI / UX (`fix-ui`)

Alias for [`ui-redesign`](../ui-redesign/SKILL.md). Follows the 4-phase visual design workflow:
1. Deep Discovery (`/grill-me`) until user satisfaction
2. 4-Layer UI Skill Orchestration (Anti-Slop Audit, Tokens & Layout, Polish & Micro-motion, Accessibility Check)
3. Responsive Viewport Verification (Mobile, Tablet, Desktop)
4. Style commit, `PROJECT-LOG.md` append, and `handoff.md` sync
